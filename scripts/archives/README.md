# Scripts d'enquête

Scripts ponctuels écrits pour comprendre le format des bulletins à un moment donné
(`inspect_*`, `scan_*`, `diagnose_*`). Ils ne font pas partie de la mise à jour du
site et ne modifient aucune donnée publiée. Ils se lancent depuis la racine du dépôt :
`python scripts/archives/inspect_report.py 177`.

*One-off investigation scripts, not part of the site update. Run them from the
repository root.*
